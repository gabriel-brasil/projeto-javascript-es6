# Animais Fantásticos

Projeto desenvolvido no curso JavaScript Completo ES6 da Origamid, com foco na utilização de JavaScript para criar interações dinâmicas em uma página web.

## Descrição

Este projeto é uma página institucional com temática de animais fantásticos, contendo:

- Menu de navegação com scroll suave
- Abas de conteúdo para visualizar diferentes animais
- FAQ em estilo accordion
- Animação de elementos ao rolar a página
- Layout responsivo e visual moderno

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript ES6
- Google Fonts

## Funcionalidades

### Navegação por abas
As opções de animais são exibidas em abas interativas, permitindo alternar entre os conteúdos de forma dinâmica.

### FAQ com accordion
A seção de perguntas frequentes usa um sistema de expansão e recolhimento dos blocos de resposta.

### Scroll suave
Ao clicar nos links do menu, a página realiza um deslocamento suave até a seção correspondente.

### Animação ao rolar
Os elementos da página entram em destaque conforme o usuário avança na página.

## Como executar localmente

1. Clone este repositório:
   ```bash
   git clone https://github.com/gabriel-brasil/projeto-javascript-es6.git
   ```

2. Acesse a pasta do projeto:
   ```bash
   cd projeto-javascript-es6
   ```

3. Abra o arquivo `index.html` no navegador.

> Como o projeto é estático, não há necessidade de instalar dependências nem iniciar um servidor.
